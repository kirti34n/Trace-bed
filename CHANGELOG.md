# Changelog

All notable repository changes should be recorded here once a human release authority and version
policy are configured. This file does not claim that the repository has released a supported
version.

## Unreleased

### Changed

- Added a loopback-only local demo launcher, isolated edge session, Validation Runs UI, and
  imported-after-execution evidence manifest.
- Added durable project provisioning and exact local-demo `data`, `admin`, and `export` grants,
  plus closed Compose lifecycle and candidate-release evidence scaffolding.
- Added a source-controlled capability contract and generated capability view.
- Reframed project documentation around an execution-derived learning sidecar and explicit limits.
- Added security, governance, contribution, conduct, support, and release-configuration guidance.
- Added fail-closed candidate-release evidence scaffolding: pinned GitHub Actions, locked build
  gates, SBOMs, vulnerability blocking, keyless signatures, provenance verification, and a
  protected human gate that deliberately does not publish.

### Removed

- Removed former host-specific adapter stubs and their dedicated tests.
- Removed an obsolete rendered HTML flow document and session handoff document.
